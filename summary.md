# summary

> LMStudio Summarizer: estensione Chrome per riassumere pagine web.

## Concetti
[[JavaScript]] [[LLM]] [[Web]]

## Panoramica
Riassume la pagina attiva con l'API di LM Studio; opzioni per modello, prompt, temperatura, font. Finestra flottante, pulsanti Summarize/Stop/Evaluate/Clear/Copy.

## Tech Stack
JavaScript, Chrome extension (Manifest). Repo: https://github.com/pakkio/summary (2024-07)
